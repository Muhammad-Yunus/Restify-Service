# Epic 27 — API Documentation (Swagger/OpenAPI)

**Goal:** Generate OpenAPI 3.0 documentation from Go annotations using swag.
**Dependencies:** Epic 13 (HTTP Router)
**Commit:** `feat: add Swagger/OpenAPI documentation generation`

---

## Step 27.01 — Swagger Annotations

**Build:** Add annotations to handler files. Example for auth handler:

```go
// @Summary Register a new user
// @Description Register a new user with email and password
// @Tags auth
// @Accept json
// @Produce json
// @Param body body dto.RegisterRequest true "Registration data"
// @Success 201 {object} dto.AuthResponse
// @Failure 400 {object} dto.ProblemDetail
// @Failure 409 {object} dto.ProblemDetail
// @Router /api/v1/auth/register [post]
func (h *AuthHandler) Register(c *gin.Context) { ... }

// @Summary Login
// @Description Login with email and password
// @Tags auth
// @Accept json
// @Produce json
// @Param body body dto.LoginRequest true "Login credentials"
// @Success 200 {object} dto.AuthResponse
// @Failure 401 {object} dto.ProblemDetail
// @Router /api/v1/auth/login [post]
func (h *AuthHandler) Login(c *gin.Context) { ... }
```

## Step 27.02 — Swagger Init

**Build:** Create `backend/docs/swagger.go`:

```go
// Package docs - Swagger documentation for ForgeBase API
package docs

import (
    "github.com/swaggo/gin-swagger"
    "github.com/swaggo/files"
)

// RegisterSwagger registers swagger handlers.
func RegisterSwagger(r *gin.Engine) {
    r.GET("/swagger/*any", ginSwagger.WrapHandler(swaggerFiles.Handler))
}
```

**Build:** Create `backend/docs/swagger.json` and `backend/docs/swagger.yaml` (generated by swag init).

---

## Step 27.03 — Generate Swagger Docs

**Build:** Add to `Makefile`:

```makefile
swagger:
	go install github.com/swaggo/swag/cmd/swag@latest
	swag init --parseDependency --parseInternal -g cmd/ForgeBase/main.go -o docs

swagger-ui:
	swag init -g cmd/ForgeBase/main.go -o docs
```

**Test cases:**
- [ ] Unit: `swag init` generates valid swagger.json
- [ ] E2E: `/swagger/*any` serves Swagger UI
- [ ] E2E: `/docs/swagger.json` returns valid OpenAPI spec
